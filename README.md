# Apache Hop Raster Type

**Development status:** implementation available.
See [implementation status](docs/implementation-status.md).

Backend-neutral, serializable raster values for Apache Hop 2.19.0 (Java 21/25).
The GeoTools 35.1 adapter evaluates bounded pixel windows. A value contains a source,
metadata and ordered operations; it never owns an open reader or a complete pixel array.

```text
Raster Reader → Raster Clip → Raster Reproject → Raster Writer
                                         └──→ Zonal Statistics
```

## Modules

- `hop-raster-core`: immutable descriptors, sources, operations, tile/reader API, bounded wire codec.
- `hop-raster-type`: `ValueMetaRaster` (type ID `727837`), registered in `sogeo-geometry`.
- `hop-raster-geotools`: local GeoTIFF/public HTTP range reads, clip, resampling and GeoTIFF output.
- `assemblies`: `hop-raster-type-plugin-0.1.0-SNAPSHOT.zip`.

The companion `hop-vector-raster-plugin` owns the user-facing transforms and ships the
GeoTools adapter. Install the matching Geometry Type, Raster Type and Vector/Raster ZIPs.
Do not copy the shared Raster model JAR into multiple plugin directories.

## Build and verification

Use JDK 21 and Maven settings generated by the pinned `hop-plugin-ci` helper:

```sh
mvn -s "$MAVEN_SETTINGS" -B -ntp clean verify
python3 scripts/verify-package.py
mvn -s "$MAVEN_SETTINGS" install
```

Build Vector/Raster afterwards. Its `scripts/run-installed-e2e.py` accepts
`--raster-type-zip` in addition to the Geometry and Vector/Raster ZIPs.

See [architecture](docs/architecture.md), [migration](docs/migration.md) and
[performance measurements](docs/performance.md).

Raster algorithms were moved from `hop-vector-raster-plugin`; its MIT license and copyright notice
are retained in [LICENSE](LICENSE). GeoTools and other dependencies retain their own licenses.
